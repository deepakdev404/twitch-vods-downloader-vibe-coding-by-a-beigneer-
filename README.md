# 🎬 VODLY

### Twitch VOD Downloader — A Modern Frontend Concept

VODLY is a modern, responsive web interface concept for downloading and managing Twitch VODs. It features a clean dark UI, VOD analysis, quality selection, custom timeline trimming, download controls, and download history.

> ⚡ **Build Story:** This project was vibe-coded from scratch in **under 5 minutes** as an experiment in rapid AI-assisted web development.

---

## ✨ Features

* 🔗 **Twitch VOD URL Analysis**

  * Paste a Twitch VOD link
  * Extract and validate the VOD ID
  * Display VOD information

* 🎚️ **Custom Timeline Selection**

  * Select specific start and end timestamps
  * Drag timeline controls
  * Manually enter timestamps
  * Keyboard-friendly controls

* 🎥 **Quality Selection**

  * 1080p
  * 720p
  * 480p
  * 360p

* 📦 **Format Selection**

  * MP4
  * WebM

* 📊 **Download Estimation**

  * Estimated file size
  * Selected duration
  * Download progress simulation

* 🕘 **Download History**

  * Stores previous downloads locally
  * Displays quality, format, duration and file size

* 🌙 **Modern UI**

  * Dark interface
  * Responsive design
  * Mobile-friendly navigation
  * Smooth animations and interactions

## ⚠️ Current Status

VODLY is currently a **frontend prototype / demo**.

The interface and interactions are functional, but the project does **not currently download real Twitch videos**.

The following components are simulated:

* VOD metadata
* Video preview
* Download processing
* Download progress
* Generated video file

Instead of downloading an actual video, the current demo generates a placeholder file.

## 🚀 Running Locally

### Option 1 — Open Directly

Download or clone the repository and open:

```text

```

in your browser.

### Option 2 — VS Code Live Server

1. Open the project in VS Code.
2. Install the **Live Server** extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.
